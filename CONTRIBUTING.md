# Contributing

Read the project instructions and [engineering SOP](https://github.com/matthewxmurphy/developer-standards/blob/main/docs/ENGINEERING-SOP.md). Use a scoped branch, preserve unrelated work and historical licenses, run focused native tests in disposable state, scan the exact Git candidate for secrets/private data, and submit a reviewable PR. Do not commit .env, runtime state, credentials or customer records. See [test and rollout notes](docs/AUDIT-SECURITY-2026-10-16.md).
