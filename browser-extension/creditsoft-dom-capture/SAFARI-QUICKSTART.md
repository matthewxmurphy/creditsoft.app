# Safari Quick Start

CreditSoft does not need a separate Safari extension yet.

## Use Safari with the same package

1. Open the report page in Safari.
2. Save the page as a Web Archive:
   `File` -> `Save As...` -> `Format: Web Archive`
3. Go back to CreditSoft.
4. Open the client dossier.
5. In `Browser evidence intake`, upload the `.webarchive` file.

CreditSoft will parse the archive, pull the page HTML into the same evidence pipeline, and keep the import on the local installation.
