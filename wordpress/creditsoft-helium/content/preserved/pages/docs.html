API docs

Updates are for installers. People go to the public site.

The update lane exists for automatic update metadata, installer packages, and daily license heartbeats. Human visitors should be sent back to www.creditsoft.app.

GET /api/update-feed

Machine-readable update metadata for installers and office nodes.

GET https://api.creditsoft.app/api/verify?key=...

License validation runs with update checks so packages are only offered to active or grace-period offices.

GET /api/install-ads

Installer creative and sponsored install cards.

GET /api/site-data

Combined site data for leads, reviews, and plans.

GET /api/leads

Public lead intake and qualification submissions.
