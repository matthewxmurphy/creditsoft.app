FAQ

Simple answers before someone reaches out.

The goal is to keep the buying path clear before someone has to ask support what each term means.

Is the website offer included in the software subscription?

No. Managed Websites is a separate branded build that starts at $495+ and ties the public site back into CreditSoft CRM, portal, and intake workflows.

Can I change plans later?

Yes. Start on the software lane the office needs today and move up when you want the browser companion or deeper automation.

What if I have more than one office?

Add a multi-office node for each additional local install. CreditSoft is designed for offices that should not all depend on one machine.

Is CreditSoft already reporting trade lines?

No. The spread-the-word program is about building demand and partnerships so CreditSoft can pursue a business-credit reporting lane with providers such as Creditsafe and Equifax.
